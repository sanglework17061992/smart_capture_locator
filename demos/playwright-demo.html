🎯 How to Test Playwright Locators:

  1. Start the Smart Locator Inspector by running: npm run dev file:///$(pwd)/demos/playwright-demo.html
  2. Hover over different elements on this page
  3. Look for the "🎭 Playwright Locators" section in the inspector modal
  4. Try elements like buttons, form inputs, navigation links, and ARIA elements
  5. Notice how Playwright locators use semantic roles and accessible names
  6. Copy the generated Playwright locators and use them in your test scripts!

📋 Expected Playwright Locator Examples

// Form elements
await page.getByLabel('Username').fill('testuser');
await page.getByPlaceholder('Enter your username').fill('testuser');
await page.getByRole('textbox', { name: 'Email Address' }).fill('test@example.com');

// Buttons and links
await page.getByRole('button', { name: 'Submit Registration' }).click();
await page.getByRole('button', { name: /Submit/ }).click();
await page.getByRole('link', { name: 'View Profile' }).click();

// Test IDs (highest priority)
await page.getByTestId('username-input').fill('testuser');
await page.getByTestId('submit-btn').click();

// Accessibility locators
await page.getByText('Subscribe to newsletter').click();
await page.getByAltText('User profile picture').hover();
await page.getByTitle('Account Settings').click();

// Navigation
await page.getByRole('navigation').getByRole('link', { name: 'Dashboard' }).click();

// Complex selections
await page.getByRole('table').getByRole('row', { name: /Alice Johnson/ }).getByRole('button', { name: 'Edit' }).click();
